# Innova Medical Aesthetics — website

Cinematic, mobile-first site for [Innova Medical Aesthetics](https://www.instagram.com/innova_birm) (Birmingham & London) with Stripe deposit booking, deployed as a Cloudflare Worker with static assets.

## Stack
- Static HTML generated by `build.mjs` from `src/data.mjs` (no framework, fast on mobile)
- GSAP + ScrollTrigger + Lenis (self-hosted in `public/assets/vendor`) for the scroll story
- Self-hosted fonts: Bodoni Moda + Hanken Grotesk
- A Cloudflare Worker (`worker/`) serves the built site from `dist` and handles `/api/checkout` and `/api/session` for Stripe deposits

## Edit content
| What | Where |
| --- | --- |
| Clinic details, practitioner, addresses, FAQs, treatment copy, images | `src/data.mjs` |
| Deposit amounts per treatment | `worker/catalog.js` (used by both the site and the payment API) |
| Styles / motion | `public/assets/css/site.css`, `public/assets/js/site.js` |

## Run locally
```bash
npm install
cp .dev.vars.example .dev.vars   # add a Stripe test key
npm run dev                      # http://localhost:8788
```

## Deploy on Cloudflare (Workers)
1. Cloudflare dashboard → Workers & Pages → Create → Import a repository → `Jamiemac9/innova_bhx`.
2. Project name `innova-bhx` (must match `name` in `wrangler.jsonc`), build command `npm run build`, deploy command `npx wrangler deploy`.
3. Worker → Settings → Variables and Secrets:
   - `STRIPE_SECRET_KEY` (type: Secret): `sk_test_…` first, then `sk_live_…`
   - `SITE_URL` (optional, plain text): e.g. `https://yourdomain.co.uk`
4. Every push to `main` rebuilds and redeploys.
5. Custom domain: Worker → Settings → Domains & Routes → Add → Custom domain. Then update `SITE.url` in `src/data.mjs` so canonicals, sitemap and schema use it.

## After launch
- Submit `/sitemap.xml` in Google Search Console and Bing Webmaster Tools (Bing feeds ChatGPT search and Copilot).
- Create/verify Google Business Profiles for each clinic with the same name, address and phone as the site.
- Stripe: Settings → Emails → turn on successful payment emails to the clinic so each deposit arrives with the booking details (stored as metadata on the payment).

## Advertising compliance (UK)
Botulinum toxin and some vitamin injections are prescription-only medicines and can't be advertised to the public (CAP Code 12.12). The site only promotes **consultations** for these, keeps them in a separate group from fillers, and never shows a treatment price next to them. Keep it that way when editing copy or social posts.
